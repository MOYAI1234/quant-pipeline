## 核心假设

- 策略想捕捉的收益来源：ETF 中期趋势延续、资产风格阶段性轮动，以及在弱势阶段降低暴露带来的回撤控制。
- 适用市场环境：趋势较清晰、风格分化明显、宽基或行业 ETF 存在持续相对强弱的阶段。
- 失效时可能出现的市场环境：快速震荡反转、同涨同跌、极端跳空、成交额萎缩、政策冲击导致历史动量失真。
- 为什么适合 ETF 投资助手：ETF 分散度较高、交易成本和容量通常优于个股；周频或月频调仓更符合真实手续费和用户操作成本，不依赖高密度网格交易。

## 因子与信号

| 项目 | 定义 |
|---|---|
| 因子 1 | 中期动量：最近 60 个交易日收益率，后续可测试 40/80/120 日敏感性 |
| 因子 2 | 短期确认：最近 20 个交易日收益率，用于过滤中期动量已经明显转弱的标的 |
| 因子 3 | 波动惩罚：最近 20 个交易日日收益率波动率，波动越高得分越低 |
| 过滤条件 | 最近 20 日日均成交额需高于阈值；上市或有效样本天数不足 120 日的标的不参与 |
| 排序规则 | 初版得分 = 60 日动量排名 + 20 日动量排名 - 20 日波动排名惩罚；具体权重在公开平台做敏感性测试后确认 |
| 买入信号 | 调仓日选择得分最高且动量为正的前 1-2 只 ETF |
| 卖出信号 | 当前持仓跌出前 N、动量转负、触发止损或流动性过滤失败 |
| 调仓规则 | 每周最后一个交易日收盘后生成目标，下一交易日按公开平台可实现时点成交；月频版本作为对照 |
| 仓位规则 | 初版等权；单标的目标仓位不超过 50%；没有标的通过过滤时持有现金或低风险债券 ETF，具体替代资产需单独验证 |

## 成本与约束

| 项目 | 假设 |
|---|---|
| 买入费率 | 先按 0.03% 记录，公开平台和券商真实费率需复核 |
| 卖出费率 | 先按 0.03% 记录，公开平台和券商真实费率需复核 |
| 单笔最低佣金 | 先按 5 元压力测试，同时保留 0 元对照以观察最低佣金侵蚀 |
| 滑点 | 初版 0.05%-0.10% 敏感性测试 |
| 成交量参与率 | 单日成交不超过对应 ETF 当日成交量的 5% 作为本地 sanity check 上限 |
| 最小交易单位 | 100 份 |
| 最大单标的仓位 | 50% |
| 最大换手或调仓频率 | 周频或月频；不做日内交易，不做密集网格 |

## 风控

- 止损或回撤控制：单标的从入场价回撤 8%-12% 区间做敏感性测试；组合最大回撤超过阈值时降仓或切到观察状态。
- 流动性过滤：最近 20 日日均成交额低于阈值的 ETF 不参与排名；阈值需在公开平台和真实 provider 中统一口径。
- 规模或成交额过滤：优先保留规模较大、成交活跃、跟踪误差和溢价率可控的 ETF；规模数据第一版可先作为人工白名单约束。
- 集中度约束：最多持有 2 只风险资产 ETF；单标的不超过 50%；同一风格或高度相关 ETF 不重复持有。
- 异常行情处理：停牌、涨跌停、缺 bar、成交额为 0 或价格异常时不生成买入信号；已有持仓进入人工复核。
- 已知失败模式：震荡市频繁反复换仓、热门资产高位追涨、短窗口参数过拟合、债券或黄金替代资产在极端环境下相关性失效。

| 本地 sanity check | 使用 TuShare / AKShare / mxdata provider 导出 rotation CSV，验证字段、复权、费用、滑点、成交量参与率和拒单归因是否可解释 |
| 公开平台 | 优先聚宽；若数据口径或 ETF 覆盖不理想，再补优矿或米筐对照 |

| 样本外区间 | 2022-01-01 至最近可用交易日 |
| 参数敏感性 | 动量窗口 40/60/80/120；调仓频率周/月；持仓数量 1/2/3；止损 8%/10%/12%；滑点 0.05%/0.10% |
| 市场阶段拆分 | 牛市、震荡、熊市和快速反弹阶段分别记录收益、回撤、换手和失败原因 |
| 对照基准 | 沪深 300 ETF、中证 500 ETF、等权持有候选池、现金或债券 ETF 替代方案 |
