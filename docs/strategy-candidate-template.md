## 进入模拟盘前检查

- [ ] 公开平台验证通过，差异已解释。
- [ ] 成本、滑点和换手后结论仍成立。
- [ ] 参数敏感性没有显示明显过拟合。
- [ ] 样本外或不同市场阶段没有不可接受风险。
- [ ] 不依赖高密度网格或不现实成交假设。
- [ ] 已记录最大回撤、最大连续亏损和容量约束。
- [ ] 已明确风控、暂停和退出条件。
- [ ] 不包含任何 token、账号、私有行情文件或受限数据。
