# 策略/因子矩阵

本矩阵用于把策略想法、因子来源和验证状态放到同一张表里。新增策略前，先判断是否符合“稳健 ETF 投资助手”的目标：低回撤、低频、真实成本可承受、多资产分散。

## 状态定义

| 状态 | 含义 |
|---|---|
| `baseline` | 已验证但不符合稳健目标，用作对照组 |
| `watchlist` | 逻辑有价值，但证据不足或需要改造 |
| `researching` | 正在补来源、因子、数据或本地 sanity check |
| `public_validation` | 值得进入聚宽、优矿、米筐等公开平台复验 |
| `candidate` | 本地和公开平台初步通过，可设计模拟盘 |
| `rejected` | 成本、回撤、复现或风险不符合要求 |

## 因子优先级

| 优先级 | 因子方向 | 原因 |
|---|---|---|
| P0 | 多资产配置、风险平价、目标波动率 | 更贴近稳健年化和低回撤目标 |
| P0 | 债券/货币/现金替代资产选择 | 当前策略防御资产太少，回撤控制不足 |
| P1 | 绝对动量风险开关 | 可用于弱市降仓，但必须验证反应延迟 |
| P1 | 低频再平衡阈值 | 降低换手和手续费 |
| P2 | 相对动量增强 | 只能作为增强项，不能牺牲回撤目标 |
| P3 | 周频或更高频轮动 | 默认不符合 ETF 稳健助手定位，除非成本后仍低回撤 |

## 维护规则

- 每个新因子必须记录来源、许可证、可复现平台、数据字段、调仓频率和成本假设。
- 最大回撤超过 15% 的结果，默认不能进入 `candidate`，除非有明确组合层风控和样本外证据。
- 本地收益很高但回撤高的策略，不优先推进。
- 聚宽/优矿/米筐验证结果需要回填到 [backtest-ledger.md](backtest-ledger.md)。
