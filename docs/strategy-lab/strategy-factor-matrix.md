# 策略/因子矩阵

本矩阵用于把策略想法、因子来源和验证状态放到同一张表里。新增策略前，先判断是否符合“稳健 ETF 投资助手”的目标：低回撤、低交易密度、真实成本可承受、ETF 主线清晰。

## 状态定义

| 状态 | 含义 |
|---|---|
| `baseline` | 已验证但不符合稳健目标，用作对照组 |
| `watchlist` | 逻辑有价值，但证据不足或需要改造 |
| `researching` | 正在补来源、因子、数据或本地 sanity check |
| `public_validation` | 值得进入聚宽、优矿、米筐等公开平台复验 |
| `candidate` | 本地和公开平台初步通过，可设计模拟盘 |
| `rejected` | 成本、回撤、复现或风险不符合要求 |

## 因子优先级

| 优先级 | 因子方向 | 原因 |
|---|---|---|
| P0 | 筛选器结果摘要输出 | 已支持 JSON/CSV 候选明细和失败原因聚合，用作后续批量挖因子的基础设施 |
| P0 | ETF 趋势防守、核心池轮动、目标仓位控制 | 保持 ETF 主线，同时控制回撤和交易密度；自适应仓位本地与聚宽结果不一致，需要先做差异排查 |
| P0 | 绝对动量风险开关 | 可用于弱市降仓或空仓，但必须验证反应延迟 |
| P1 | 低交易密度阈值 | 允许日评估，但降低无效换手和手续费 |
| P2 | 相对动量增强 | 只能作为增强项，不能牺牲回撤目标 |
| P3 | 日内多次交易或密集网格 | 默认不符合 ETF 稳健助手定位，除非成本后仍低回撤且执行约束可证明 |

## 维护规则

- 每个新因子必须记录来源、许可证、可复现平台、数据字段、调仓频率和成本假设。
- 最大回撤超过 15% 的结果，默认不能进入 `candidate`，除非有明确组合层风控和样本外证据。
- 本地收益很高但回撤高的策略，不优先推进。
- 不默认通过债券、黄金或类存款资产降低回撤；如使用非权益 ETF，必须证明它服务于 ETF 策略目标，而不是把项目改造成资产配置建议。
- 聚宽/优矿/米筐验证结果需要回填到 [backtest-ledger.md](backtest-ledger.md)。
- 本地批量筛选结果先经过 [自动准入门槛](execution-gates.md)，只有 `PASS` 候选才默认进入公开平台复验队列。
- 日评估策略必须区分“评估频率”和“成交频率”：允许每天看信号，但准入时仍按真实成交笔数过滤，不允许靠日内反复交易制造回测收益。
