# 稳健 ETF 策略研究台账

本目录是 ETF 投资助手的策略研究总入口。当前目标不是追逐最高回测收益，而是在真实成本和低频交易约束下寻找更稳健的 ETF 资产配置方案。

## 当前定位

ETF 投资助手的优先目标是：

- 在风险可控的前提下追求稳定年化。
- 优先降低最大回撤、回撤恢复时间和连续亏损月数。
- 使用月频、季度频或更低频的调仓节奏，避免依靠高密度交易。
- 组合应优先考虑宽基权益、债券、黄金、货币或现金替代等多资产配置，而不是只在高波动 ETF 之间追涨切换。
- 项目内回测只作为工程 sanity check；公开平台和未来模拟盘记录才是策略有效性的核心证据。

## 稳健准入目标

| 指标 | 目标 | 说明 |
|---|---|---|
| 年化收益 | 6% 至 10% | 高于该区间不是坏事，但不能以显著提高回撤为代价 |
| 最大回撤 | 优先低于 10%，上限 15% | 超过 15% 的策略默认只能作为研究基线或观察项 |
| 调仓频率 | 月频或更低 | 周频策略需要证明扣除滑点和最低佣金后仍有稳定优势 |
| 资产数量 | 至少包含低波资产 | 债券、货币、现金替代或其他低波资产需要参与风险预算 |
| 成本假设 | 保守 | 必须包含买卖佣金、最低佣金、滑点和成交容量约束 |
| 验证层级 | 本地 -> 公开平台 -> 模拟盘 | 不允许只凭本地回测进入实盘预研 |

## 当前结论

现有三个策略都还不符合“稳健 ETF 投资助手”的候选标准：

| 策略 | 当前定位 | 主要原因 |
|---|---|---|
| `ETF-MOM-ROT-001` | 高换手/成本敏感基线 | 周频动量轮动在本地成本压力下收益不足，最大回撤约 24.89% |
| `ETF-DUAL-MOM-002` | 低换手但高回撤基线 | 252 日版本交易次数低，但最大回撤约 27.50%，不符合稳健目标 |
| `ETF-DAA-003` | 风险开关实验观察项 | canary/breadth 月末风险开关未明显降低回撤，对快速下跌反应滞后 |

下一轮策略发现应优先寻找低回撤、多资产、低频的配置方案，例如股债黄金现金组合、风险平价、目标波动率、全天候、绝对动量降仓和保守再平衡。

## 下一步

1. 把现有策略保留为高回撤基线，不再作为稳健主线推进。
2. 建立新的 P0 方向：股债黄金现金、风险平价、目标波动率、全天候和绝对动量降仓。
3. 先登记来源和因子，再做本地 sanity check。
4. 只有最大回撤接近 10% 至 15% 目标的方案，才进入聚宽或其他公开平台复验。
